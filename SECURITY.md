# Signaler un problème de sécurité

Les versions publiques maintenues sont les dernières releases du dépôt. Les versions locales antérieures restent des versions de développement.

Pour une vulnérabilité, utiliser **Security → Advisories → Report a vulnerability** dans GitHub si cette fonction est activée. Ne pas publier de jetons, inventaires privés ou accès au serveur dans une issue publique. Si le signalement privé est indisponible, ouvrir une issue sans détail exploitable pour demander un canal de contact.

Le plugin vérifie les empreintes des paquets et délègue un seul périphérique USB à un conteneur sans réseau. Le gestionnaire Unraid et les fichiers de configuration nécessitent les droits administrateur. Les signatures de release ne sont pas fournies ; les sommes SHA-256 vérifient l’intégrité des fichiers téléchargés.
