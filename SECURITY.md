# Reporting a security issue

The latest public release is maintained. Earlier local releases are development builds.

For vulnerabilities, use **Security → Advisories → Report a vulnerability** on GitHub if enabled. Do not publish tokens, private inventory or server access in a public issue. If private reporting is unavailable, open an issue without exploitable details to request a contact channel.

The plugin verifies package hashes and delegates one USB device to a container with no network access. The Unraid manager and configuration files require administrator privileges. Releases are not signed; SHA-256 checksums verify downloaded file integrity.
